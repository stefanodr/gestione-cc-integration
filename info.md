# Gestione C/C

**Italiano:** Integrazione HACS per monitorare lo stato tecnico dell'Home Assistant App Gestione C/C e avviare tre operazioni di manutenzione autorizzate. Non importa dati contabili in Home Assistant. Richiede l'App Gestione C/C già installata, un URL HTTPS locale, un certificato CA attendibile e un token dedicato.

**English:** HACS integration for technical monitoring of the Gestione C/C Home Assistant App and for starting three authorised maintenance operations. It does not import accounting data into Home Assistant. Requires the Gestione C/C App to be installed, a local HTTPS URL, a trusted CA certificate and a dedicated token.
