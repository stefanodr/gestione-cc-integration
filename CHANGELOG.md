# Changelog

All notable changes to this integration are documented here.

## 1.1.15 — Initial release in the dedicated repository

- Extracted the existing `gestione_cc` Home Assistant custom integration from the combined App repository.
- Preserved the integration domain, config flow, coordinator, entities, unique IDs, platforms and current implementation.
- Updated documentation and issue tracker URLs to this repository.
- Added bilingual Italian/English installation, configuration, API, privacy and troubleshooting documentation.
- Added HACS and Hassfest validation workflows.

This repository split does not itself change the integration's runtime behaviour or require an immediate reinstall.
